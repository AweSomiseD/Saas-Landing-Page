# Biccas - SaaS Landing Page

A modern and responsive SaaS landing page built with HTML5 and Tailwind CSS. Biccas showcases a productivity-focused software platform through a clean layout, feature highlights, pricing plans, and engaging visual sections.

## ✨ Features

- Responsive navigation bar with desktop and mobile menus.
- Modern hero section with call-to-action buttons.
- Partner and brand showcase section.
- Customer support and ratings section.
- Product features and benefits sections.
- Three pricing plans: Free, Pro, and Business.
- Testimonial section.
- Contact and demo request interface.
- Newsletter subscription interface.
- Modern footer with multiple navigation sections.
- Smooth hover effects and interactive UI styling.

## 🛠️ Technologies Used

- **HTML5** - Page structure and semantic elements.
- **Tailwind CSS** - Utility-first styling and responsive layouts.
- **CSS3** - Styling and visual presentation.
- **Google Fonts** - Typography using Inter, Poppins, Playfair Display, and Volkhov.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/AweSomiseD/Saas-Landing-Page.git
```

**2. Navigate to the project directory**

```bash
cd Saas-Landing-Page
```

**3. Open the project**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
